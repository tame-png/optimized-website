Three inline marks taken from the uploaded first draft, rendered in the low-tide values (an `<img>` cannot read tokens, so these files are fixed-colour; in a page, paste the SVG inline and bind fills to `accent`, `gold`, `ink`, `signal` and `sea-tint` as the Plate and PostcardFooter previews do).

- `pyramid-stamp.svg` (78×90): the postcard stamp, a dotted `accent` frame around the Walter Pyramid in `gold` with `ink` stroke. Use it as the favicon (replacing the Vite default) and in the PostcardFooter.
- `wave-divider.svg` (1200×28): the two hairline waves, `accent` over `gold-deep`. The WaveDivider component draws the same paths with token-bound strokes; use the file only in email or print.
- `bathymetry-plate.svg` (420×240): the San Pedro Bay plate from the hero: a `sea-tint`→`accent` wash, five isobaths, the gold sun, the pyramid wireframe and four data nodes. Hero only, inside a ticked Plate.

There is no logo file; the wordmark is plain type (see the README's Logo section).
